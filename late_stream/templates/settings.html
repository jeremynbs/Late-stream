Synology NAS

Use a dedicated DSM user with read-only access to the recordings folder, File Station permission, and no 2-step verification.

Email alerts

Alerts are always sent for failures (file check failed, stream dropped, failed, missed, couldn't unlist). For Gmail use smtp.gmail.com, port 587, STARTTLS and an App password.

YouTube (optional)

Streaming only needs the stream key. Connecting YouTube lets the app switch the video to Unlisted after the stream, and start the broadcast if Auto-start was left off. Uses about 60 of the free 10,000 daily API units per stream.
